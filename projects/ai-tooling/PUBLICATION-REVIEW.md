# 公共源码归档核对

本次公开内容限定为插件、技能、API 接入、扩展与测试工具的源码、构建模板、文档和原有许可文件。与完整本地审查包相比，已排除所有图片、PDF、模型、压缩媒体、论文全文、未改动的上游整仓副本和大规模协议／市场数据。

## 已核对项目

- 收录文件与 `SOURCE-MANIFEST.json` 的 SHA-256 一致；Git 以原字节保存。
- 所有收录 JSON 和 Python 文件通过语法解析；本机凭据、认证状态、真实数据库、浏览器 profile、依赖缓存及取证输出不在公开树中。
- 凭据扫描命中已逐项查看：WorkBuddy 三个测试中的 `private-access-token`、`private-refresh` 和 `do-not-store` 是模拟响应值；Gemini 的 `dont-import-password` 是解析器负例。其余发现位于被排除的 DSH 上游测试。未把这些测试常量描述为真实凭据，也未通过改写字符串规避扫描。
- Gemini 的 31 项本地合成测试、Chat Image Bridge 服务端租约／幂等性测试通过；不调用真实付费模型。
- Live2D Kit 的完整本地副本结构检查通过；65 项单元测试为 52 通过、5 跳过、2 失败、6 错误，涉及 Windows 可执行格式、符号链接权限和 fixture 补丁校验。本公开副本不包含模型和美术示例，不能用完整包的结构检查结果声称该源码副本包含全部运行资产。
