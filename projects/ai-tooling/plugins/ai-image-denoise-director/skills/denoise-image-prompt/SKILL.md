# AI 生图去噪提示词导演

把本技能作为“参考图/原始意图”和“生图或图像编辑模型”之间的中间流程。目标不是盲目追求无纹理，而是移除非预期噪点，同时保留用户要的媒介质感、主体身份、构图和色彩关系。

## 工作流

1. 收集已有输入：参考图、当前图、原提示词、目标风格、使用模型/界面、最终用途。若信息不足但仍可推进，直接分析现有材料，并将假设写入结果；只有缺少目标图时才请求上传。
2. 视觉诊断：使用可用的图像查看能力检查全图与关键局部。将现象分为：
   - 非预期噪点：随机彩点、色块、蚊噪、脏污、压缩伪影、边缘振铃、过度锐化光晕、条带、背景碎纹。
   - 生成伪影：重复纹理、融化边缘、错误文字、异常手指/五官、材质粘连。这些不是传统噪声，需局部重绘或重新生成。
   - 有意纹理：胶片颗粒、纸张纤维、炭笔粉尘、半色调、像素抖动、画布纹理。除非用户明确要求，不把它们列为待清除项。
3. 提取风格锚点：主体及身份特征、轮廓与姿态、构图/镜头、光向、主色与色彩比例、材质、媒介、细节密度。参考图之间冲突时，以用户明确要求优先，其次以主参考图优先。
4. 选择最低干预策略：
   - 轻微随机噪点且结构正确：全图低强度编辑/去噪。
   - 噪点集中或伴随结构错误：局部遮罩重绘，只描述目标区域和必须保持的邻接关系。
   - 全图风格/结构已漂移：重新生成，但把风格锚点和不可改变项写在前部。
5. 生成提示词。按“任务动作 → 主体与不可变项 → 风格与媒介 → 构图镜头 → 光色 → 材质细节 → 缺陷约束”的顺序组织。使用具体可观察描述，删除重复、互相冲突或只会空泛抬高画质的词。
6. 适配模型：自然语言编辑模型使用完整编辑指令和保持项；支持 negative prompt 的扩散模型另给精简负向词；不确定模型语法时给通用版本，不臆造权重、采样器或参数。
7. 输出一次可验证的 A/B 迭代：A 为保守清理，B 为更强清理。每次只改变去噪强度或一个缺陷簇，要求固定 seed/构图（若工具支持），比较后再继续。

## 决策边界

- “高清、8K、masterpiece”不能替代缺陷诊断。只有与目标风格相容时才使用质量词。
- 不同时要求“完全无颗粒”和“真实胶片颗粒”；应改为“去除随机彩色噪点，保留细腻均匀的银盐颗粒”。
- 不把所有负面词堆成通用长串。只包含已观察到的缺陷、该题材高风险缺陷和明确禁用内容。
- 对照片写实，避免过度平滑、塑料皮肤、蜡质表面和锐化光晕；对插画，保护笔触、纸纹、网点或像素边缘。
- 若噪点来自低分辨率、JPEG 压缩或放大流程，应指出提示词只能降低再次生成的风险，不能可靠恢复已丢失信息。
- 不声称单靠提示词能保证完全消除噪点。需要时建议局部重绘、较低编辑强度、分阶段放大或传统降噪，但不擅自执行付费/外部操作。

## 输出格式

默认用中文说明，提示词语言遵循目标模型习惯。按以下顺序给出：

1. **诊断**：噪点类型、位置、严重度，以及应保留的有意纹理。
2. **策略**：轻度全图编辑、局部重绘或重新生成，并说明选择原因。
3. **优化提示词**：可直接复制的主提示词。
4. **负向约束**：仅在目标模型支持时提供；否则合并成“不要改变/避免”自然语言。
5. **保持项**：主体、构图、色彩、光线、材质等不可漂移项。
6. **A/B 方案**：保守版与加强版的唯一差异。
7. **检查表**：噪点是否下降，纹理是否仍自然，边缘/文字/五官是否受损，风格是否漂移。
