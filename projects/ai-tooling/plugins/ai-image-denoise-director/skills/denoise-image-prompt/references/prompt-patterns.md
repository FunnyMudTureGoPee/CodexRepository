# 去噪提示词模式

## 通用编辑模板

```text
在不改变【主体身份/造型】、【构图与镜头】、【主色与光向】的前提下，清理【位置】的【已观察缺陷】。
将随机、斑驳的噪点替换为【符合目标媒介的连续材质】；保留【有意纹理】。
恢复自然的边缘过渡和局部层次，不新增物体、文字、图案或高频细节。
```

负向提示词仅按需抽取：

```text
random chroma noise, blotchy texture, compression artifacts, ringing halos,
oversharpening, banding, dirty background speckles, repeated micro-patterns
```

不要默认添加与观察无关的解剖、NSFW、签名或水印词。

## 风格适配

- 写实摄影：保留毛孔、织物纤维和真实微反差；抑制彩色噪点、蜡质皮肤、HDR 光晕和过度磨皮。
- 胶片：清除不均匀彩噪、压缩块和脏斑；保留细腻、均匀、与曝光一致的银盐颗粒。
- 动漫/赛璐璐：保护干净线稿和分色边界；抑制边缘毛刺、色块内散点、脏渐变和重复纹理。
- 水彩/传统媒介：保护纸纹、渗色和笔触；只清除数字彩噪、JPEG 块和突兀锐化边缘。
- 3D/产品渲染：保持几何、材质和轮廓；抑制采样噪点、萤火点、阴影斑点和反射中的颗粒。
- 像素艺术：像素网格、有限色板和有意抖动属于风格；只清除非网格插值、模糊边缘和孤立异色像素。

## 冲突消解

按以下优先级保留要求：用户明确声明 > 主参考图的核心身份/构图 > 目标风格 > 次要参考图 > 通用质量词。

发现冲突时改写成可兼容表述，例如：

- “无颗粒 + 胶片感” → “无随机彩噪，保留细腻均匀的胶片颗粒”。
- “极致锐利 + 柔和梦幻” → “主体轮廓清晰，背景保持柔和扩散”。
- “真实皮肤 + 完美无瑕” → “肤色均匀但保留自然毛孔与微小纹理”。

## A/B 强度

- A 保守版：只移除随机彩噪、压缩伪影和明显孤立斑点；所有结构与媒介纹理锁定。
- B 加强版：在 A 基础上减少背景高频碎纹和重复纹理，但仍保护主体边缘与材质。

若平台提供编辑/重绘强度，先从低强度开始；不同平台标尺不可互换，不给未经核验的固定数值。
