# 台账格式

每份台账使用 UTF-8。首行用一级标题说明范围。每条记录用二级标题和稳定 ID 起头，ID 由大写英文字母、数字和短横线组成，同一台账内唯一。紧跟标题的三行元数据供浏览页筛选，顺序不限。状态使用「待验证」「已验证」或「已替代」，日期使用本地日历的 YYYY-MM-DD。正文用短段落和普通 Markdown 链接组织。只有条目标题使用二级标题。

```markdown
# 项目记忆

## [STARTUP-001] 第二次进入 Play 时启动状态异常
- 模块：启动
- 状态：待验证
- 更新：2026-11-09

**触发**　关闭 Domain Reload 后连续进入两次 Play Mode。

**结论**　待确认是否有静态状态在第二次启动时沿用。

**下次怎么做**　分别验证首次和再次启动，记录两次的初始化路径。

**证据**　链接到复现记录或实际改动。当前仅有复现描述。
```

已有 `docs/known-issues.md` 或别的项目知识库时，接入前确认其定位。若项目约定沿用旧台账，按原格式维护并保留原链接。需要离线筛选时，可以在用户要求迁移时将选定条目整理成上述格式，并保存原证据。
