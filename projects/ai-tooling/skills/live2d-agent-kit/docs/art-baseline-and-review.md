# 美术基准与拆层审查

用于重绘、图层过多、色差、局部接缝、恢复旧版或用户认为“没有之前好”的情况。
目标是保住已认可的外观，用必要的绑定层实现目标动作。

## 先锁定“哪张图、哪个版本、哪一方面”

不同资料可以分别定义设计、画风和运动，不应强行指定一张图支配所有方面。

| 基准 | 应记录的内容 |
| --- | --- |
| 角色设定 | 双侧部件、配饰结构、正侧背面的关系 |
| 已认可画面 | 确切版本名、工程路径、同姿态预览、主要素材哈希 |
| 目标动作 | 具体部位、运动方向、范围、响应与回落 |
| 本轮变更 | 替换哪些素材或绑定；保持哪些已认可区域 |

用户说“最初那版”“这一版”时，用截图、工程名、动作名和交付记录定位，展示或检查该版缩略图。
不能自行替换成最初母图、最新文件夹或重新生成的“更精细”画风。
候选版本仍冲突时，只询问这个差异；可继续做文件盘点与只读对比，暂停依赖基准的重绘。
用户指定新基准后，尚在生成队列中的旧方向结果不得自动导入。

“设定图优先”用于设计事实；具体版本可定义画风与比例；用户也可指定某个局部采用另一参考。
记录这种分工。例如对称耳机可由设定图确定，后发衔接采用用户指定立绘效果。

## 拆层是运动设计，不是细节数量竞赛

区分三件事：画出的发束数量、独立绑定层数量、网格/关键值数量。
减少重复图层不意味着把线稿、明暗、细发丝或高光抹成大色块；增加节点也不保证嘴型更自然。
先列出独立运动与遮挡需求，再决定是否拆层。

用户要求拆前审查时，按其要求提供逐层表；现有授权已覆盖的修复直接执行，
只对新的实质范围变更重新审查，不把每次小调色、位置修复都变成新的批准流程。

逐层表应包含：
- 语义名与双重侧别：角色左/右、画面左/右；再对应真实 layer ID，不能只靠 L/R 猜。
- 素材区域与可见像素归属；被遮挡的根部、轮廓和内侧如何完整补绘。
- 层序、父级/固定点、独立运动、与相邻部件的覆盖关系。
- 合并、略去或缺失的部件及其对目标动作的影响。

“整个头部”按用户实际定义盘点。常见范围是脖子以上：
脸、耳、眉眼口、前发、侧发、后发、顶部发束、马尾、发饰和耳机。
不能只完成面部就宣称整头完成。项目中的俗称须建立部件映射，避免把顶部发环与下垂双马尾改错。

## 重绘与保留应由问题决定

用户要求完整重绘的组件，应绘成连贯实体，包括隐藏区域，不能用低分辨率可见残片代替。
例如无眼五官底片是连续皮肤；发片有完整发根和轮廓；耳机画到实际佩戴点。
保留已经认可的五官与肤色基准，重绘不等于任意换脸。

已有认可素材没有问题时，优先复用该版本素材，重新生成只会增加漂移机会。
只有需要独立注视或光效时才把瞳孔、高光、阴影分层；发丝内部细节通常可以画在同一绑定层。
分层后先独显确认每层职责，再合成，排查“完整旧前发 + 新前发 + 自带刘海的发底”三重轮廓。

只修色差时，比较色相、明度、阴影、高光位置、线宽和材质；主色落在同一统计区间只是辅助证据。
同一色值也可能因不同阴影、透明度或轮廓产生明显不一致。
统一颜色不能顺便改变发量、发梢走向和细节密度。
画面变复杂时，优先移除重复可见轮廓，让补片承担隐藏补绘，而非叠加另一套完整发型。

## alpha 和高清检查

- 同时检查 RGBA 与实际合成到深、浅背景的效果。alpha=0 的 RGB 光晕不一定可见。
- 发片内部意外半透明会透出肤色，形成色斑；它不是调色问题，也不是外轮廓白边。
- 同一生成参考反复产生相同缺陷时，停止沿错误结果叠加重绘，回查参考、透明通道与轮廓，
  改用干净的已认可输入；不要不断导入有缺陷的素材再靠盖片补救。
- 保持源坐标、逻辑尺寸、网格和 UV 注册关系。裁透明外边距后必须记录偏移。
- 区分完整绘制的高分辨率源图、编辑器采样图、逻辑注册图和运行时图集；
  放大低清残片或增加 PNG 尺寸不等于补回细节。

## 进入绑定前的美术检查

按相同姿态、相同缩放对比选定基准与新合成，至少看：
轮廓/发量、五官与肤色、线条层次、色调与明暗、白边/透明洞、配饰结构、局部衔接。
初次素材合成可能同时显示备用嘴/闭眼层，须说明它只是素材检查图，不能冒充最终中性姿态。
用真实模型中性渲染再检查一次。

出现明显画风、细节或身份退化时，不继续把该稿导入当前工作工程。
回到少量失败部件修复，再装配复核。工具成功、主色一致、Core 通过均不能替代美术判断。
将“素材通过”“工程切片/绑定待检”“用户实机待审”分开记录。
