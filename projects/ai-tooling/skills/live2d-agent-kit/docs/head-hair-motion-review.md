# 整头、配饰与头发运动检查

适用于整头跟随、耳机穿帮、发片僵硬、发梢不自然，以及转头后波动回落。

## 运动归属先于振幅

记录每个部件的头部父级、附着点、自己的运动参数和遮挡层。
顶部发束、发饰、后脑与双马尾根部应随头部共同运动；不能只有脸在转。
颈部承担头身过渡，不能把身体一并当成头部附件移动。

耳机等佩戴物按真实佩戴点固定。先确认贴耳位置和局部朝向，再安排头发在其前后遮挡。
前发可以滑过耳机，但耳机不应继承前发物理而漂离耳朵。
正面遮住部分、转头后显露，是有意的层序设计；不能靠永久压在所有头发上方解决。
必要的侧发底层应补足显露处，尽量不改变已认可的正面轮廓。

先查角度正负、角色侧别、枢轴和父级，再修转头时的前发相对位移与透视压缩。
不要凭“向左转”直接给所有前发同一个屏幕平移量。
在头部两端与发梢反向摆动的组合中检查，默认姿态正确不够。

## 区分几种症状

| 症状 | 优先检查 |
| --- | --- |
| 整块发片像木板 | 根部约束、沿长度变化的弯曲、网格是否能表达弧度 |
| 发梢折角或扭结 | 分段之间的位置与切线是否连续、局部弯曲权重是否突变 |
| 转头停下就瞬间停止 | 是否有带状态的物理过程，而不只是角度到位移的静态映射 |
| 所有部位同相摆动 | 上中下段是否共享一个输出仅乘不同振幅 |
| 顶部发环扭曲很大 | 是否误用了长马尾的增益、活动长度与自由端范围 |
| 马尾像绳子但发饰被拉长 | 发饰固定点与根段变形是否一致，配饰是否错误继承末端弯曲 |
| 强摆动才露出耳机悬空 | 耳机固定位置、隐藏轮廓、头发层序与物理组合 |

顶部发环、短后发和长马尾的长度、柔度不同，分别调节。
不要为修复一个部件统一缩放全部头发振幅。

## 绳状传递与回落

用户要求“像波一样向下传递”时，目标是时间上的响应先后：
根部受头部输入驱动，中段随后弯曲，末端再响应，输入停止后余振衰减。
把同一信号乘三种幅值只能改变摆幅，不能证明波动传递。

可使用有约束的多粒子链，或等价的连续分段曲线与有状态延迟系统。
让各段输出映射到自己的弯曲区域，发根保持附着；各段位置和切线连续，发束宽度随曲线转向。
三段是已验证过的实用示例，不是所有角色的硬性规格。
若引擎通过多个相同链实例读取不同粒子输出，各实例必须有一致输入、初态和积分时序；
不要将其误描述成不存在的单实例多输出能力。

先用短促转头→停住→反向→再停的输入定位惯性与回落，再调整幅度、延迟、阻尼和重力。
输出限制可防止夸张折叠，但不应把所有末端运动夹死。
具体数值和坐标依角色比例、模型参数范围与物理引擎重新测量，不照搬示例常数。

## 静态与动态分别留证

静态检查：
- X/Y/Z 的默认与端点；左右部件独立摆动。
- 头部极限与反向发梢/马尾摆动、头身反向的必要组合。
- 耳部固定点、发根、发饰连接、后发衔接和马尾遮挡。
- 参数恢复后，选定几何/透明度能回到相同初态。

动态检查：
- 实际物理求值的短促转头、保持、反向、停止回落。
- 保存帧时间、输入参数、上中下段输出和渲染图；检查响应先后及衰减。
- 在穿帮风险最高的中间帧也观察耳机、发根和遮挡，不只看两端。
- 记录是否存在 idle、呼吸或自动眨眼叠加。输入归零不等于模拟总输出必然为零。
- 检查片段须有足够停止后的时间，避免把仍在受驱动的动作描述为自由回落。

数值 Core 检查、参数求值后合成图、SDK 渲染器播放、用户目标软件实机是不同证据层。
例如“physicsSimulated=true + Cubism exported model parameters; CPU image compositor”
说明该工具执行物理/参数路径并合成画面，不等于 Cubism Editor、VTube Studio 或 Unity 验收。
有限轨迹通过不能证明全参数空间；抽查联系表不能写成全帧人工检查。
沿用旧验证时必须先确认对应模型与贴图的哈希未变。
