# 更新记录

## 0.7.1

修复工作流在线判断，使用 Koishi `Universal.Status.ONLINE`；图片生成与导入统一校验数字/字符串用户 ID，保留严格归属检查，支持合法 ID 0，未配置改为 null。自动配图增加可选 `presetName`，工具授权失败列出不匹配的名字。MCP 改用无状态 Streamable HTTP，取消 30 分钟空闲会话回收，保留逐请求鉴权、GET 405 和发信幂等；不自动重放工具调用。升级脚本备份旧 lib（含 bak 文件）。63 项自动测试通过；目标电脑的真实 ChatLuna/MediaLuna/SMTP 联调待升级后验收。

## 0.7.0

新增受控工具工作流：任务可选择工具模式，经管理员授权的 ChatLuna Agent 调用搜索、歌曲库等读取类工具，再生成图文邮件；含执行身份、工具白名单、步数/调用/超时/入参/结果预算、失败策略、撤权停止、并发锁和重启核对。新增 MCP `import_mail_image` 与任务内 MediaLuna 自动配图，只接受成功任务、指定用户、本地 PNG/JPEG 缓存。旧任务默认保持上下文模式。默认上下文预算放宽为 64000 字符、历史 60 条、模型超时 120 秒；工作流默认 10 步／16 次调用／300 秒／16000 字符结果。新增 `scripts/upgrade.ps1` 自动升级脚本（SHA256 校验、配置备份、自动识别包管理器、版本核对）。60 项测试在 Node 22 与 Koishi Node 20 下通过。

## 0.6.3

修复 save_mail_task 的 runAt 空字符串枚举造成 Gemini HTTP 400 INVALID_ARGUMENT；对外使用字符串，服务端保持单次任务必填及 ISO 日期/时区校验。增加实际 MCP 工具声明扫描，50 项测试通过。升级后重连 MCP 更新工具缓存。


## 0.6.2
