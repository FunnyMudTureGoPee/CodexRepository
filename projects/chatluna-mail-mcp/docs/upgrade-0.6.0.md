# 0.6.0 升级与使用

本版解决模型不可选、任务表单难理解、变量需要手写 JSON，以及 Agent 无法创建任务和模板的问题。继续使用单个 ChatLuna 模型，根据主插件预设和指定会话上下文判断是否发信。

## 安装

退出或重载前先备份 Koishi 实例配置和数据库。安装新版包后重启插件，并刷新浏览器页面。
不需要重新导入任务、模板和图片；原来 task.model 的覆盖语义保留，空模型仍跟随会话，不自动改用新默认模型。

在 PowerShell 执行（脚本会寻找 Koishi 自带运行时）：

```powershell
& "D:\AI\文献\koishi-plugin-chatluna-mail-mcp\scripts\install.ps1"
```

也可以使用 Koishi 实例的 Yarn 手动安装：

```powershell
Set-Location "$env:APPDATA\Koishi\Desktop\data\instances\default"
& "C:\Program Files\Koishi\Desktop\bin\koishi.exe" ".\.yarn\releases\yarn-4.1.1.cjs" add "koishi-plugin-chatluna-mail-mcp@file:D:/AI/文献/koishi-plugin-chatluna-mail-mcp/dist/koishi-plugin-chatluna-mail-mcp-0.6.0.tgz"
```

MCP URL 和 Bearer Token 不变。重连 MCP 后工具数由 9 增为 13。

## 模型设置

打开「邮件任务 → 模型设置」，刷新 ChatLuna 模型目录，选择并保存邮件默认模型。
供应商、接口地址和 API Key 在 ChatLuna 模型适配器配置；本插件不复制密钥，也不新增独立 LLM 服务。
这里列出 ChatLuna 已注册的聊天模型，不展示 embedding/rerank 模型。

每个任务有三种选择：

- 跟随会话模型：使用该会话当前模型，保持旧任务行为。
- 邮件默认模型：使用上述保存的默认值，后续默认值变动会影响这些任务的下一次判断。
- 指定一个模型：本任务固定使用所选模型，不受邮件默认值影响。

目录与上下文诊断不会请求 LLM 生成。「试判断」会产生模型调用，但不自动发信。
目录存在不等于上游服务调用成功。模型不可用时停止该次判断，不自动切换模型。

## 简化任务配置

1. 填写中文任务名称、收件人并选择模板；任务内部 ID 留空自动生成。
2. 从最近 100 个活跃会话中选择上下文会话，再选择判断模型。
3. 选择每天、每周或仅一次。年/月/日、小时、分钟和常用时区均使用下拉框；每周用星期勾选。
4. 填写判断与写作要求，检查中文计划摘要，再保存。

单次时间按所选执行时区转换，不取决于浏览器本机时区。月份和闰年自动限制日期，夏令时中不存在的时间会提示调整。
高级设置默认折叠，保留手动会话 ID、预设覆盖、特殊时区、消息范围、预算、冷却和重试等参数；编辑旧任务不会丢失这些设置。
新任务默认停用；可勾选「保存后启用定时任务」。总开关关闭时仍不会定时发信。错过计划分钟不补发。

## 变量卡片

模板编辑页点击「添加变量」，每张卡片填写：

- 变量名称：例如 person，使用字母、数字、横线或下划线，不填花括号。
- 必填：启用任务或预览时必须提供值，除非已有非空默认值。
- 默认值：任务未填写时使用。
- 预览值：只用于当前排版预览，不会保存进任务。

点击「插入提示词」或「插入页脚」将 {{person}} 插入对应文本的最近光标位置；未选择位置时追加到末尾。
任务选择此模板后出现变量值卡片，也能把变量插入判断要求。任务变量会替换模板提示词、任务判断要求及页脚中的同名占位符。
主插件预设需要的额外变量仍可在高级设置中配置。任务提示词中的占位符需要在所选模板中声明；旧任务中仅作为字面示例的 {{name}} 应调整或声明。
变量重复、名称非法、引用未声明变量或缺少必填值会拒绝保存/执行，并提示检查。模型正文与变量在 HTML 输出中转义。

## Agent 自主创建

在本插件配置中开启 allowAgentManage（默认关闭），授予持有本机 MCP Bearer Token 的 Agent 任务和模板管理能力。
该权限包含读取活跃会话目录、创建/修改/启停所有邮件任务，以及创建/更新自定义模板；共用令牌的 Agent 共享此权限。
关闭此开关会禁止新的管理调用，不会删除或停用已保存任务；需要停止计划时停用任务或关闭发信总开关。

新增工具：

| 工具 | 用途 |
|---|---|
| get_mail_configuration | 查询 ChatLuna 模型、预设、最近活跃会话目录、白名单与邮件默认模型，不返回密钥和历史正文 |
| get_mail_task | 获取任务完整定义、下次执行和 hash |
| save_mail_task | 创建任务或按 hash 更新；完整替换任务定义，可设置 enabled |
| save_mail_template | 创建自定义模板或按 expectedVersion 更新 |

创建用 expectedHash="" / expectedVersion=0；修改前读取当前版本，冲突后重新读取，不覆盖他人新修改。
内置模板不可覆盖，可换新 ID 创建。任务数量上限仍为 50。
Agent 不可通过这些接口修改 SMTP、白名单、总开关、密钥或邮件默认模型设置，也不开放本地文件读取和图片导入。

allowAgentSend 控制即时 send_mail_draft；allowAgentManage 控制计划管理。被授权创建并启用的任务可在未来自动判断与发信，即使即时发信权限关闭；
它仍受 enabled 总开关、收件白名单、冷却、频率限制、任务当前状态和幂等约束。
save_mail_task 本身不发信。enabled=true 是持续的计划授权；Agent 应依据用户要求设定，不能把聊天上下文中的命令视为用户授权。

示例调用顺序见 [agent-setup.json](../examples/agent-setup.json)。
