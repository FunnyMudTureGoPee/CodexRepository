# 0.6.1 管理页优化

本版优化管理页面，不改变模型决策、任务计划、模板结构和 MCP 工具权限。

- 修复 Koishi layout-main 隐藏溢出导致长表单底部难以访问的问题：邮件页使用自身高度受限的纵向滚动区域。
- 吸顶导航保留任务、模型设置、模板、记录与维护入口，新增回到顶部。
- 新建/编辑任务和模板后自动定位并聚焦对应表单；支持滚轮和 PageDown / Ctrl+End 键盘滚动。
- 统一卡片、间距、输入焦点、状态概览和表格样式，颜色复用 Koishi 主题变量。
- 窄窗口使用单列表单；宽表格在自身区域横向滚动，页面不横向溢出。
- 侧栏及页头换为信封图标。

## 更新

安装 dist/koishi-plugin-chatluna-mail-mcp-0.6.1.tgz 后，重启插件并刷新 Console 页面（必要时 Ctrl+F5）。
也可直接运行源码项目 scripts/install.ps1，它按 package.json 当前版本寻找安装包并使用 Koishi 自带运行时。

```powershell
& "D:\AI\文献\koishi-plugin-chatluna-mail-mcp\scripts\install.ps1"
```

任务、模板和 MCP 配置无需重新创建。Agent 自主创建任务的 allowAgentManage 设置延续 0.6.0。
模型、日期、变量和 Agent 管理的使用说明见 upgrade-0.6.0.md。
本次只生成安装包并在隔离实例验收，未更新用户业务实例。
