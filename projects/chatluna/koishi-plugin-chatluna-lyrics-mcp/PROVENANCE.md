# 来源与许可

本目录归档本机留存的 `koishi-plugin-chatluna-lyrics-mcp` 源码，版本 `0.1.1` 来自原项目的 `package.json`。保留源码、测试、构建配置、示例和当时锁定的项目依赖。锁文件已移除指向本机 `0.1.0` 压缩包的旧 Koishi 联调项目条目。

在项目目录运行 `pnpm check` 可执行类型检查、测试和构建。测试入口会为编译的测试写入 `test-build/package.json`，沿用原项目生成目录中的 CommonJS 声明。打包方式见项目的 [README](README.md)。
