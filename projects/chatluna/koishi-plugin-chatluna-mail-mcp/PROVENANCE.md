# 来源与许可

本目录归档本机留存的 `koishi-plugin-chatluna-mail-mcp` 源码，版本 `0.7.3` 来自原项目的 `package.json`。保留服务端、控制台客户端、测试、示例、锁文件和原项目文档。文档中的本机目录已替换为占位路径或相对路径。

在项目目录运行 `pnpm check` 可执行类型检查、测试和构建。构建通过 `tsup.config.ts` 生成 `lib/` 和 `console/`。打包方式见项目的 [README](README.md)。

原项目源码目录中未发现单独的许可证文件或 `package.json` 许可声明。归档沿用原项目的许可状态。
