## 3. 四部分改动细节

以下幅度为拟定调校目标，不是现有效果或已通过的验收结果。像素统一指逻辑画布像素；末端位移扣除身体与父级刚性运动后测量。执行前在中性姿态登记跟踪点与局部坐标，修改前后沿用同一组点，不按截图缩放后的像素计数。

### PHY-A 胸部

- 在 `ArtMeshImage_19` 前增加独立局部 Warp，置于既有肩臂形变之后，不向 `T15UpperArms` 增加参数轴。
- 新增 `ParamChestPhysicsX`、`ParamChestPhysicsY`，范围 `[-1,1]`，默认 0；以身体左右、俯仰、倾斜产生惯性，呼吸仅作弱驱动。
- 上下响应为主、左右为辅。正常动作纵向约 2–4px、横向约 1–2px；极限分别不超过 6px、3px。
- 左右区域协调响应，不做独立反向弹跳。领口、肩根、臂环、中央连接饰物和腰线设为固定或平滑归零区域，保持衣服图案连续。
- 停止输入后约 0.5–1 秒内回稳。不让局部胸部形变传播到大臂、颈部、腰线或整块躯干。

### PHY-B 常态与挥手衣袖

**常态袖：**

- 分别处理两侧实际可见袖片，复用现有袖身、袖尖控制，补足弱呼吸输入。
- 根部跟随手臂，袖身和末端分阶段响应；角色左侧垂手袖前片和内层保持共用运动关系。
- 待机袖端约 1–3px；标准身体摆动下约 4–8px。末端比袖身明显滞后，停止后约 1–1.5 秒回稳。
- 保持袖口厚度和包围关系，不以整片硬板旋转替代布料形变。

**挥手袖：**

- 保留 `ParamT8Sleeve` 整体延迟，新增 `ParamWaveSleeveTip`，范围 `[-1,1]`、默认 0，控制前后袖片的局部末端，不作用于手或小臂。
- 物理输入覆盖挥手、肩部跟随及水平朝向变化；先核对各输入的实际来源，避免同一运动通过两条路径被重复放大。
- 挥手袖端约 8–16px。手臂先变向，袖身随后、末端最后回弹；停止后允许 1–2 次逐渐减弱的回摆，约 1–1.5 秒回稳。
- 保持手掌、小臂位置，以及已确认的袖前—手臂—袖后遮挡关系；同时复查肩根和腋下，不只检查袖口末端。
- 垂手和挥手袖分别保留物理状态；姿势切换不重置整套身体物理，不修改既有差分显隐规则。

### PHY-C 正面两侧腰间挂饰

- 复用 `body-hip-r/l` 的根部与末端两段控制；连接件随腰部近似刚性运动，垂带逐渐增加柔性。
- 对应既有输出为 `ParamT2HipR/L`、`ParamT3HipRTip/LTip`。两侧按形状分别调校，不强制完全同步。
- 呼吸下末端约 1–2px；标准身体摆动下约 6–12px。转向时滞后，停止后有短暂余摆，约 1.2–2 秒回稳。
- 连接点不脱离腰部，几何连接饰件不拉成软布，文字和图案不明显扭曲；与裙摆重叠区域无新增穿插或排序跳变。

### PHY-D 裙摆

- 复用 `DeformT2Skirt` 及 `ParamT2Skirt`、`ParamT3SkirtTip`；重新分配裙腰固定区、上段低权重区、下摆高权重区。
- 身体运动为主输入，呼吸为弱输入；裙身先响应，下摆稍后回落，两侧边缘保持连续形变。
- 呼吸下摆约 1–2px；标准身体摆动下约 6–12px；停止后约 1–1.8 秒回稳。
- 保留裙褶、装饰线、裙长与遮挡，不以整裙平移、大幅掀起或牵动腿部实现摆动。

幅度目标用于正常动作调校，所有极限组合仍须满足衔接与造型要求。不能为达到位移数值牺牲画面质量；若两者无法兼得，记录未通过项和原因，由总控协调范围调整，不自行降低验收标准。

## 4. 共同驱动与兼容约束

新增参数共三个：`ParamChestPhysicsX/Y`、`ParamWaveSleeveTip`。已有参数 ID、姿势参数、正式动作名称和动作时长保持兼容。若复核发现参数已存在，先核对语义，禁止重复创建同名控制。

- 使用现有物理机制，新增局部 Warp 不扩大已有多轴近似网格。
- 物理输出只由物理解算写入；动作和鼠标控制器不得同时覆盖这些输出。
- 呼吸作为弱输入，不制作独立持续抖动动画；不新增持续微风输入。
- 原有头发物理继续运行，其设置及输出不属于本轮修改范围；四部分不得形成新的物理驱动环。
- 在现有运行框架内保持单次物理更新，不附加第二套重复解算。

拟议帧更新顺序（语义约束，不是可直接调用的 API）：

```text
应用当前动作与呼吸
应用既有头眼、身体和手臂追踪
由同一套物理解算更新胸部、衣袖、挂饰、裙摆输出
更新 Cubism 模型
完成渲染后记录图像、时间和实际参数
```

### 6.2 定量与视觉标准

- **回稳定义**：固定所有输入后，输出围绕该姿态平衡值的残余振幅降至本次峰值的 10% 以下，持续至少 0.5 秒。非中性姿态不强制输出归零。呼吸驱动仍开启时不能当作“全部输入停止”的回稳测试。
- **固定点**：相同基础姿态下，开启与关闭本轮新增或调整的物理响应，领口、肩根、袖根、腰饰连接点及裙腰的额外位移不超过 0.5px。
- **视觉**：100% 逻辑尺寸及 200% 局部放大，深浅背景均无新增可见露底、裂缝、重影、穿插、图案断裂或轮廓突变。
- **数值**：无非有限坐标；受改动区域不得新增三角形翻转。已有警告保留并注明，不以 Core 整体加载成功掩盖局部问题。
- **稳定性**：无持续能量增长、反复撞限或长时间贴住参数上下限；快速反向后仍可收敛。
- **帧率一致性**：预热后对齐相同时间，目标跟踪点 30/60fps 差异 95 分位不超过 1px、最大不超过 2px；不通过时修正时序或解算，不降速掩盖。
- **中性回归**：新增参数归零、物理关闭、其他输入相同，T29 中性外观保持一致，受保护区域几何误差不超过 0.1px。
- **新旧输出归属**：确认所有物理输出只有一个写入者，动作/鼠标不覆盖，参数 ID、范围、默认值及实际可见对象映射一致。
- **真实物理证据**：必须实际推进物理解算，并在渲染完成后采集。T30 无物理 GIF 不可作为本轮验收依据。
- **复查范围**：连续检查四个目标区域的编号帧序列，另保留全身上下文；注明漏帧、抽查或只看局部的范围，不能把抽查写成逐帧通过。
- **审美确认**：技术通过后提交同输入前后对比，由用户确认“自然但可见”的强度与节奏；此前记为“技术通过、视觉待确认”。

验收平台为 PSD2Live 编辑检查和实际 Cubism Web 渲染。Web 结果不替代原生工程重开，PSD2Live 的静态或 CPU 合成图不冒充实际 Web 物理播放；Unity、VTube Studio 和摄像头不列入本轮通过条件。
