# 维护约束与验收

- 保持独立离线 HTML 交付，不引入运行时 CDN、服务端或大模型依赖。
- 主体为洛天依；示例素材内嵌，仅归档当前用户提供的版本，不额外声明素材授权。
- 不恢复光翼、面部保护或中文歌词绘制。历史歌词解析字段仍兼容旧配置。
- 不增加固定 350×300 构图预设；尺寸与人物位置由用户调整。
- 环带与消散取点必须独立；编辑辅助线不进入输出。
- 保留下方线框和终端交互感；不恢复横贯顶部的框线及大标题。
- 出血以成品坐标为基准向外扩展，不向内裁切、不缩放人物。
- 调整毫米尺寸、PPI、出血后检查 SVG 物理尺寸和印刷 PNG 元数据。

## 人工验收

1. 直接打开 HTML，上传 PNG/JPG/WebP 和 MIDI，导入导出配置。
2. 分别点击环带、消散及触碰锚点，确认互不改变。
3. 切换辅助线及终端标注，检查预览与 PNG/SVG 输出。
4. 保持成品比例一致，切换 0/3/5 mm 出血，确认内部布局不移动、范围向外扩展。
5. 用浏览器导出印刷 PNG，核对含出血像素尺寸与 PPI；测试超限提示。

## 当前限制

SVG 文本仍依赖查看器的等宽字体，未转曲；打印前需在目标排版软件核对。SVG 中位图仍受源分辨率限制。印刷输出保持 RGB，不提供 CMYK、ICC 或白墨分层。印刷 PNG 限制为 6400 万像素、单边 16384 像素。
