# 洛天依二进制绘制器

归档版本：V21。独立 HTML，内含 CSS、JavaScript 和示例图片；下载后直接用桌面浏览器打开，无需服务器、安装依赖或调用大模型。

## 使用

打开 `Tianyi_Binary_Studio.html`，上传人物底图，调整画布、人物和字符参数；可导入 MIDI 设置数据环带。保存的 JSON 配置不包含用户上传的底图、背景或 MIDI，请单独保留。

- 重组、全息触碰、普通字符画像。
- MIDI 环带：独立中心锚点、起始角度、环绕范围、淡化范围、前后层次、音符柔光和亮度。
- 消散：方向、中心、四周及角度模式；与环带取点独立。
- 终端标注、下方线框与编辑辅助线。
- 成品毫米尺寸、出血、SVG 和指定 PPI 的印刷 PNG。

## 印刷与出血

原画布定义成品区域。出血向外扩展，不改变原画布内人物的布局；越界矢量继续绘制，背景底色向外铺满。上传位图缺失的内容不会自动补画。成品毫米比例须与画布比例相符，否则印刷导出会提示调整。

SVG 使用毫米尺寸，矢量没有固定 PPI。印刷 PNG 通过 SVG 栅格化，按含出血尺寸与 PPI 计算像素，并写入 PNG pHYs 信息。普通 PNG 导出成品画布。裁切线仅在明确勾选校样导出时写入印刷图；编辑辅助线不导出。

## 开发验证

运行环境 Node.js；测试依赖只用于开发，HTML 本身无外部依赖。

```sh
npm install
npm test
```

测试使用模拟 DOM 与原生 Canvas，覆盖 MIDI 解析、渲染、独立锚点、角度淡化、终端开关、出血几何及 PNG 分辨率元数据。不能替代浏览器内上传、下载和 SVG 栅格化的人工验收。
